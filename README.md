# The Tiebreaker ⚖️

> Intelligent decision engine featuring multi-framework analysis and real-time collaborative group voting to eliminate analysis paralysis and break deadlocks.

🔗 **Live Demo:** [the-tie-breaker-inky.vercel.app](https://the-tie-breaker-inky.vercel.app/)

---

## ✨ Features

- **Multi-Framework Analysis**:
  - **Pros & Cons**: Impact weights (1–5) with actionable risk mitigations for every downside.
  - **Comparison Matrix**: Dynamic criteria weight sliders (1–10) with live score recalculation.
  - **SWOT Canvas**: 2×2 internal & external strategic quadrant breakdown.
  - **The Verdict**: Objective ruling with confidence score, core trade-offs, and conditional guidance.
- **Collaborative Group Voting**:
  - Real-time rooms with 5-character shareable codes.
  - Ranked Choice (Borda count), 1–10 ratings, and 100-point budget allocation.
  - Live Recharts consensus bar chart visualization.
  - Team arguments feed and 1-click stakeholder simulation.
  - AI Mediator to break deadlocks and propose hybrid compromises.
- **Gut-Check Coin**: Psychology-backed digital coin flip to reveal subconscious preferences.
- **Flexible Exports**: One-click download as **PDF** report, **CSV** spreadsheet (for Excel / Google Sheets), or **Markdown**.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS
- **Visualization & Export**: Recharts, jsPDF
- **Backend**: Express, Node.js
- **Icons & UI**: Lucide React, Canvas Confetti
